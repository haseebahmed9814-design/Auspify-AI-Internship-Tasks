## 💻 General Setup & Installation

1. **Clone this repository**:
   ```bash
   git clone https://github.com/haseebahmed9814-design/Auspify-AI-Internship-Tasks.git
   cd Auspify-AI-Internship-Tasks
   ```

2. **Navigate to a specific task and install dependencies**:
   ```bash
   # Example: Task 1
   cd Task_01
   pip install -r requirements.txt
   jupyter notebook Task01.ipynb

   # Example: Task 2
   cd Task_02
   pip install -r requirements.txt
   jupyter notebook Task02.ipynb
   ```

3. **For Task 3 & Task 4** (no separate requirements.txt — use common packages):
   ```bash
   pip install pandas numpy scikit-learn matplotlib seaborn
   ```
