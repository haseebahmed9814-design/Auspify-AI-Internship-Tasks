## 💻 General Setup & Installation

1. **Clone this repository**:
   ```bash
   git clone https://github.com/haseebahmed9814-design/Auspify-AI-Internship-Tasks.git
   cd Auspify-AI-Internship-Tasks
   ```

2. **Navigate to specific task (e.g. Task 1)**:
   ```bash
   cd Task_01
   pip install -r requirements.txt
   jupyter notebook notebooks/Task01.ipynb
   ```
